# gimp-calendar
GIMP用カレンダー生成プラグイン。Version 3.0以降

- 画像に一ヶ月分のカレンダーを生成
- カレンダーは画像の1/4サイズで、四隅(左上・右上・右下・左下)に配置
- 祝日は日本の暦(2026年時点)を使用

# インストール
GIMPのplug-insフォルダにコピー。

```
> copy gimp-calendar "C:\Users\{アカウント名}\Application Data\GIMP\3.0\plug-ins"
```

# 使い方
カレンダーを生成した画像を開き、`フィルター(R)`-`Python-Fu`-`Plug-in Calendar in Python3`を選択


|項目|内容|
|----|----|
|年|生成する年|
|月|生成する月|
|月の文字色|年・月に使う文字色|
|前景フォント|曜日・日付に使うフォント名|
|背景フォント|年・月に使うフォント名|
|位置|カレンダーを生成する位置(左上・右上・右下・左下)|
